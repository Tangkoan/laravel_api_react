Laravel គឺប្រើប្រាស់ក្បូនសរសេរជា MVC 
M = Models     (path: \app\Models)             
V = View       (path: \resources\views)
C = Controller (path: \app\http\controller)


=> Model
        ប្រើដើម្បីអ្វី? * Model គឺជាអ្នកទទួលបន្ទុកលើ ទិន្នន័យ (Data) និង Database។
            វាធ្វើការទាក់ទងដោយផ្ទាល់ជាមួយ Database ដើម្បី ទាញយក (Select), បញ្ចូល (Insert), កែប្រែ (Update) និង លុប (Delete) ទិន្នន័យ។
            រាល់ការគណនា ឬ Logic ដែលពាក់ព័ន្ធនឹងច្បាប់ទម្លាប់របស់ទិន្នន័យ គឺត្រូវសរសេរនៅទីនេះ។

=> View
        ប្រើដើម្បីអ្វី?
            View គឺជា ចំណុចប្រទាក់អ្នកប្រើប្រាស់ (User Interface / UI)។
            វាជាអ្វីដែលអ្នកប្រើប្រាស់មើលឃើញនៅលើអេក្រង់ (ជាទម្រង់ HTML, CSS, JavaScript ឬ Blade template)។
            View មិនមានតួនាទីទៅទាញទិន្នន័យពី Database ខ្លួនឯងនោះទេ គឺវាគ្រាន់តែរង់ចាំទទួលទិន្នន័យដែលគេបោះឲ្យ ដើម្បីយកមកបង្ហាញឲ្យបានស្អាតប៉ុណ្ណោះ។

=> Controller 
        ប្រើដើម្បីអ្វី?
            Controller គឺជា អ្នកកណ្តាល (Middleman) ឬជាខួរក្បាលបញ្ជា។
            នៅពេលមាន Request ពីអ្នកប្រើប្រាស់ (ឧទាហរណ៍៖ ចុចលើប៊ូតុង ឬវាយ Link) Controller គឺជាអ្នកទទួលដំបូងគេ។
            វាសម្រេចចិត្តថាត្រូវទៅបញ្ជា Model មួយណាឲ្យទៅយកទិន្នន័យ ហើយបន្ទាប់មកវាទាញយកទិន្នន័យនោះទៅប្រគល់ឲ្យ View ណាមួយដើម្បីបង្ហាញទៅកាន់អ្នកប្រើប្រាស់វិញ។

ឧទាហរណ៍ងាយយល់ (ប្រៀបធៀបទៅនឹងភោជនីយដ្ឋាន)៖
        => View គឺដូចជា អតិថិជន និងតារាងម៉ឺនុយ៖ ជាអ្វីដែលយើងមើលឃើញនៅខាងក្រៅ។

        => Controller គឺដូចជា អ្នករត់តុ (Waiter)៖ ទទួលការកុម្ម៉ង់ពីអតិថិជន (View) យកទៅប្រាប់ចុងភៅ ហើយចាំយកម្ហូបដែលឆ្អិនហើយ មកឲ្យអតិថិជនវិញ។
        
        => Model គឺដូចជា ចុងភៅ និងផ្ទះបាយ៖ មិនខ្វល់រឿងទទួលភ្ញៀវទេ គឺដឹងត្រឹមថាបើអ្នករត់តុប្រាប់ឲ្យធ្វើម្ហូបអី គាត់នឹងស្វែងរកគ្រឿងផ្សំ (Database) មកចម្អិនឲ្យឆ្អិន រួចហុចឲ្យអ្នករត់តុវិញ។










ខាងលើគ្រាន់តែនិយមន័យខ្លះខ្លះ ខាងក្រោមគឺយើងនឹងរៀនទាក់ទង Route

=>  Route ជាផ្លូវសម្រាប់ Website ឬ System ដែលយើងបង្កើត 127.0.0.1:8000/api/role (Route នេះសម្រាប់ API)
    ឬ ម្យ៉ាងទៀត​ 127.0.0.1:8000/login ( pageសម្រាប់ Login )

*** Laravel 11 - 12 up គឺត្រូវការ install file api.php 
> php artisan install:api
ក្រោយពី Run Command ខាងលើរួចយើងនិងទទួលបាន File ..\routes\api.php ដែលជាកន្លែងសម្រាប់ដាក់ Route របស់ API
ចំពោះ web.php ក៏ Route ដែរប៉ុន្ដែសម្រាប់ដាក់ Route អោយ View
