Controller Command To Create File Controller
> php artisan make:controller ProductController
=> ករណីយើងចង់ដាក់ Floder admin រួចបានដាក់ File ចូលក្នុង Floder នោះ
> php artisan make:controller admin/UserController
                              admin/user/UserController
                              admin/product/ProductController
ពេលខ្លះយើងអាចចង់ដាក់ Controller នោះជា File របស់API
> php artisan make:controller api/ProductController --api
មូលហេតុដែលបន្ថែម --api គឺដើម្បីអាចអោយវាបង្កើត Function មកស្រាប់
